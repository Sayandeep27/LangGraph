# 1️⃣ Reducer (Annotated)

## 🔹 What is a Reducer?

A **Reducer** defines how updates to the same state key are combined when multiple nodes write to it.

Without a reducer → values overwrite each other
With a reducer → values are merged

---

## 🔹 Why is it needed?

Multiple nodes may update the same state:

```python
state = {
    "messages": []
}
```

If two nodes return:

```python
{"messages": ["Hello"]}
{"messages": ["How are you?"]}
```

Without reducer → one overwrites
With reducer → both are preserved

---

## 🔹 Annotated Reducer

LangGraph uses `Annotated` from `typing` to attach reducers.

```python
from typing import Annotated, TypedDict
from operator import add

class State(TypedDict):
    messages: Annotated[list, add]
```

---

## 🔹 How it Works

| Step | Update             | Result                      |
| ---- | ------------------ | --------------------------- |
| 1    | `["Hello"]`        | `["Hello"]`                 |
| 2    | `["How are you?"]` | `["Hello", "How are you?"]` |

---

## 🔹 Common Reducers

| Reducer         | Purpose            |
| --------------- | ------------------ |
| `operator.add`  | Append lists       |
| `operator.or_`  | Merge dictionaries |
| Custom Function | Custom merge logic |

---

## 🔹 Custom Reducer Example

```python
def merge_unique(old, new):
    return list(set(old + new))

class State(TypedDict):
    tags: Annotated[list, merge_unique]
```

# 2️⃣ Checkpointer

## 🔹 What is a Checkpointer?

A **Checkpointer** saves the state of the graph at each step of execution.

Think of it like a **"save game" system**.

---

## 🔹 Why is it Important?

* Resume execution
* Debug workflows
* Maintain chat history
* Fault tolerance

---

## 🔹 Example (In-Memory)

```python
from langgraph.checkpoint.memory import MemorySaver

checkpointer = MemorySaver()
```

---

## 🔹 Using Checkpointer in Graph

```python
graph = builder.compile(checkpointer=checkpointer)
```

---

## 🔹 What Gets Saved?

* State
* Execution progress
* Node transitions
* History

---

# 3️⃣ Persistence

## 🔹 What is Persistence?

Persistence means storing state **long-term**, beyond a single execution.

---

## 🔹 Checkpointer vs Persistence

| Feature  | Checkpointer | Persistence |
| -------- | ------------ | ----------- |
| Storage  | Temporary    | Long-term   |
| Lifetime | Execution    | Permanent   |
| Example  | Memory       | Database    |

---

## 🔹 Types of Persistence

1. In-memory (temporary)
2. File-based
3. Database (SQLite, PostgreSQL, Redis)

---

## 🔹 Example (SQLite Persistence)

```python
from langgraph.checkpoint.sqlite import SqliteSaver

checkpointer = SqliteSaver("graph.db")
```

---

## 🔹 Why Use Persistence?

* Production systems
* Long-running workflows
* Multi-user sessions
* Stateful applications

---

# 4️⃣ Literal (Routing in LangGraph)

## 🔹 What is Literal?

`Literal` restricts a value to predefined options.

---

## 🔹 Example

```python
from typing import Literal

def route(state) -> Literal["node_a", "node_b"]:
    if state["score"] > 5:
        return "node_a"
    return "node_b"
```

---

## 🔹 Why Important?

* Ensures valid routing
* Prevents errors
* Improves type safety

---

## 🔹 Conditional Edges Example

```python
builder.add_conditional_edges(
    "router_node",
    route,
    {
        "node_a": "node_a",
        "node_b": "node_b"
    }
)
```

---

## 🔹 Flow

```text
Router → returns "node_a"
Graph → moves to node_a
```

# 5️⃣ 🔥 End-to-End Example

```python
from typing import TypedDict, Annotated, Literal
from operator import add
from langgraph.graph import StateGraph

class State(TypedDict):
    messages: Annotated[list, add]
    next: str

# Node 1
def node1(state):
    return {"messages": ["Hello"]}

# Router
def router(state) -> Literal["node2", "end"]:
    return "node2"

# Node 2
def node2(state):
    return {"messages": ["World"]}

builder = StateGraph(State)

builder.add_node("node1", node1)
builder.add_node("node2", node2)

builder.set_entry_point("node1")

builder.add_conditional_edges("node1", router, {
    "node2": "node2",
    "end": "__end__"
})

# Compile graph
from langgraph.checkpoint.memory import MemorySaver

checkpointer = MemorySaver()

graph = builder.compile(checkpointer=checkpointer)
```

# 6️⃣ 🎯 Key Takeaways

| Concept      | Core Idea                            |
| ------------ | ------------------------------------ |
| Reducer      | Defines how state updates are merged |
| Annotated    | Attaches reducer to state field      |
| Checkpointer | Saves execution progress             |
| Persistence  | Stores state long-term               |
| Literal      | Controls routing decisions           |

---

# 🧠 Final Intuition

* **Reducer** → How data combines
* **Checkpointer** → Save current progress
* **Persistence** → Store forever
* **Literal** → Decide next step safely

---

# ⭐ Best Practices

* Always use reducers for list/dict states
* Use persistence in production apps
* Use Literal for routing safety
* Combine checkpointer + persistence for reliability
